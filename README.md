# Mobile Sector Product Portfolio Analysis July 2026
> Оцінка товарів мобільного сегменту інтернет-магазину, в цілях набуття та демонстрації практичних навичок збору даних, стандартизації, візуалізації, і загалом аналізу.

# Мета роботи
Проаналізувати ринок мобільної продукції, асортимент компаній та цінове позиціонування продуктів.
Для кращого розуміння ситуації мобільної індустрії варто відповісти на такі запитання:

- Загальна кількість компаній та їх продуктів
- Який відсоток продуктів представлено в різних цінових категоріях?
- Як споживачі оцінюють продукти компаній залежно від його вартості?

# Збір даних
Дані були взяті із сайту української компанії allo. До них входять всі продукти, що були у наявності у категорії "Телефони" станом на липень 2026 року. 
Для автоматизації збору інформації було використано бібліотеки Python під назвою BeautifulSoup та Pandas. З їх допомогою було можливо отримати html-код сторінки і з отриманого файлу вибрати необхідну інформацію. 
До неї входило:
- ID продукту
- Компанія (перше слово з назви продукту)
- Назва продукту
- Вартість
- Рейтинг
- Кількість оцінок

Далі інформація була поміщена до таблиці, а сама таблиця була збережена у [файл](https://github.com/postigle/Mobile-Sector-Product-Portfolio-Analysis-July-2026/blob/main/Mobiles_scrapped.csv)
Код для збору даних: [файл](https://github.com/postigle/Mobile-Sector-Product-Portfolio-Analysis-July-2026/blob/main/Scraping_mobiles_from_website.ipynb) 

# Очищення та стандартизація даних

Для автоматизації першого етапу очищення даних було використано мову Python та бібліотеку Pandas для роботи із таблицею. 
- колонку рейтинг було скорочено та очищено колонку рейтинг від зайвих символів та приведено до одного формату
- в колонці ціна було прибрано пропуск для подальшої зміни типу даних
- колонка компанія була наближена до ідеалу шляхом знаходжена окремих записів з некоректними значеннями

# Відповіді на питання

Серед проаналізованих даних виявилося 55 компаній з кількістю товарів близькою до 3 тисяч. 

Лідерами за середньою вартістю продуктів виявилися компанії Apple, Vivo та Asus.
У цінових категорія продукти середнього класу мають невелику перевагу над бюджетними пристроями (908 проти 885) та сильно відриваються від товарів флагманського та субфлагманського сегментів (614 та 542). Що відображає

Оцінкка споживачів не критично відрізняється у бюджетних та продуктах середнього класу, та є доволі високою, що вказує на задоволення продуктом за свою ціну. Флагманські пристрої мають найвищу середню оцінку, вона наближається до 10 і вказує на виправдану ціна за якісний продукт. В той же час оцінка субфлагманських дещо просіла на деяких компаніях, що може свідчити про поганому співвідношенні ціни та якості продуктів окремих компаній. В інших же компаніях даної категорії рейтинг лишається високим.
